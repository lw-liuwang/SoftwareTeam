# SoftwareTeam v0.6.12

SoftwareTeam 的首次 GitHub 源码发布，基于 OpenRig 0.6.11。
团队工作空间就是本仓库，固定岗位和项目知识长期保留，继续使用 OpenRig 的现有终端。

## 本次内容

- 七位常驻专家及团队专属技能：调度、需求、架构、开发、评审、测试、运维。
- PR 和产品两条工作流，包含调度检查、返工重验、架构实现核对、实际测试和需求验收。
- PR 无需跟进到合并；产品还需部署及线上复测。
- 仓库内的独立岗位工作目录、共享和岗位知识、持久工作记录及结构化交接格式。
- 事故恢复与永久整改分开记录，架构风险及标准变更保留人类决策权。

## 使用

需要 Node.js 22 或 24、tmux，以及已登录的 Codex 或 Claude Code。
从此标签的源码构建，具体步骤见 [README](../../README.md)。

```bash
npm ci
npm run build
npm run team:prepare -- --runtime codex
```

准备命令不启动专家。人类审定候选 SOP 并确认运行时后，按 README 使用既有
`rig up` 和 `rig terminal open` 命令启动与查看团队。

## 验证

团队改造相关的 57 项测试、构建和类型检查已通过。
Git 和变更日志补齐后的仓库检查结果将在发布前更新到本说明。

## 已知边界

本版交付源码、团队配置及候选 SOP，不代表真实团队已运行或产品已上线。
MCP、运维技能来源、部署目标和资源预算尚待接入。
工作流约束路由与状态；证据内容、人类审批身份和代码版本变化尚未获得引擎强制验证。
不向上游 `@openrig` npm 命名空间发布，不升级或重启现有 daemon。
