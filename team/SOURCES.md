# 专属技能的方法来源

本团队技能按岗位责任、交接依据和闭环要求重新编写，没有安装上游完整工作流，
也不把上游默认规则自动视为本团队已批准标准。版本状态见 `standards.yaml`。

| 岗位 | 指定来源 | 采用的方法 |
| --- | --- | --- |
| 调度 | [socrates-skill](https://github.com/nuwa-skills/socrates-skill) | 澄清术语、检验假设、通过具体情境讨论分歧 |
| 需求 | [requirement-analysis](https://github.com/FlameMida/spec-dev/tree/main/skills/requirement-analysis) | 场景、范围、验收条件和需求追踪 |
| 开发 | [superpowers](https://github.com/obra/superpowers) | 测试驱动、系统排障、验证后报告完成、处理评审反馈 |
| 评审 | [code-review-skill](https://github.com/awesome-skills/code-review-skill) | 上下文审查、问题严重性、定位和可操作依据 |
| 测试 | [awesome-ai-test-skills](https://github.com/kenchikuliu/awesome-ai-test-skills) | 测试方法导航；该仓库不是可直接执行的完整技能包 |
| 测试参考 | [webapp-testing](https://github.com/anthropics/skills/tree/main/skills/webapp-testing) | 适用时检查真实页面、交互、日志和截图 |
| 架构 | [software-architecture-skills](https://github.com/45ck/software-architecture-skills) | ADR、质量场景、边界、风险与取舍 |
| 运维 | 待补充 | 目前按已确认的资源、部署复测和事故整改责任编写候选 SOP |
| 创建方法 | [skill-creator](https://github.com/anthropics/skills/tree/main/skills/skill-creator) | 技能适用范围、资源组织和验证 |

上游工具、脚本、许可证和账号不会因链接出现在这里而自动安装或授权。
当前内容为针对团队需求重新编写的操作说明，未复制上游实现或模板。
后续复用上游代码或大段文本时，应保留对应版本的许可证及归属声明；
Anthropic webapp-testing 为 Apache-2.0，其他来源以各仓库相应版本为准。
